# Security policy

This repository is the umbrella for the companion materials of a scientific
paper. In its current skeleton state it holds only documentation and
citation metadata; by `v1.0` it will additionally hold the paper-specific
scripts used to drive the component-repo simulations and to post-analyze
their output. It does not, and will not, host the generic simulation
machinery (which lives in the linked component repositories) or raw
simulation outputs (which will be archived on Zenodo). The component
repositories carry their own maintenance and (where applicable) security
policies.

## Reporting a problem

If you discover a problem with the materials in this repository that you
believe should be reported privately rather than via a public issue (for
example: an accidentally-committed credential or private path, a misuse of a
third-party dataset's license, or a serious error in a reproduction
instruction that you don't want to publicise until it is fixed), please
contact the repository maintainer directly:

- **Dorri Halbertal** — <d.halbertal@stardust-initiative.com>

For routine bug reports, documentation problems, or reproducibility questions,
please open a GitHub issue instead.

## Supported versions

Only the `main` branch and the most recent tagged release are actively
maintained. Older tags are kept for the historical record (they reflect the
state of the repository at specific points in the paper's life cycle —
submission, revision, final publication) and will not receive security
updates.

| Version | Supported |
|---|---|
| `main` (latest commit) | yes |
| Most recent tag        | yes |
| Older tags             | no — historical only |
